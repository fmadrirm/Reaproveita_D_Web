♻️ Reaproveita

Site de orientação para o reaproveitamento de resíduos domésticos - ODS 12

Projeto da disciplina de Desenvolvimento Web – Ciência da Computação, Universidade Federal da Fronteira Sul (UFFS) Campus Chapecó.

Sobre:

O Reaproveita auxilia pessoas a decidir o que fazer com um resíduo antes de jogá-lo fora. Basta pesquisar o item que tem em casa (de cascas a garrafas PET) e encontrar ideias práticas de reutilização, com passo a passo e linguagem simples.

O projeto está alinhado à ODS 12 – Consumo e Produção Responsáveis, especialmente às metas 12.3 (desperdício de alimentos), 12.5 (redução de resíduos, reciclagem e reuso) e 12.8 (informação e conscientização).

Funcionalidades:
- Busca por resíduo
- Páginas de ideias com passo a passo
- Navegação por categorias (Recicláveis e Orgânicos)
- Design responsivo (celular e computador)
- Página sobre a ODS e os dados

Tecnologias utilizadas:

HTML · CSS · Tailwind · GitHub
